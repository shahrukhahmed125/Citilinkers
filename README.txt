# Citilinkers — HTML, CSS & JavaScript

This version removes the React, TypeScript, Vite and build setup. It contains static HTML pages, a CSS stylesheet, vanilla JavaScript and the original image assets.

## Pages
- index.html
- about.html
- services.html
- faq.html
- blog.html
- contact.html
- account.html

## Run
Open `index.html` in a browser, or upload the complete folder contents to your hosting public_html directory.

Tailwind utility classes are loaded through the Tailwind CDN. Google Fonts, Font Awesome, Swiper and GSAP are also loaded from their CDNs where used. An internet connection is required for these external resources.

Note: Booking, account and contact interactions in the supplied project are front-end/demo interactions. A live booking/payment/login backend must be connected separately.
